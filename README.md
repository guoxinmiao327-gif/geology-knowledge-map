# 地质事件与研究方法 · 回顾地图

在线访问：[打开知识地图](https://guoxinmiao327-gif.github.io/geology-knowledge-map/)

以地质年代和研究方法为两条主线的中文可视化知识库，基于课程 PPT 导出 PDF 整理，未读取教材。

- 42 个地质事件、42 种研究方法、22 个研究案例、40 个基础专题。
- 37 份课程课件，3118 页/幻灯片；129 张事件/方法图版与4组长期指标曲线。
- 全部 3118 页原图与文字、按课程逐页回顾、阅读进度、基础专题、知识关联。
- 完整地质年代表、事件磁吸聚焦、课件图版并排核对、全文检索。
- 近黑背景与白色玻璃卡片，NASA贴图蓝色三维地球；按UTC一天一圈，悬停放大。
- 三维地球依赖与贴图随站点打包，WebGL 2不可用时显示静态地球。
- 课件标注已登记的本地文件更新时间；外部研究标注已知发表年份，未核定日期明确说明。
- 保留原课件图版中的作者与年份，补充研究附原始来源链接。
- 图表各自保留原始坐标，不能视为共用时间轴；年龄范围及争议请查看条目说明。

此仓库发布网页成品。全部课程页图像以内容指纹命名的 course-*.js 按需载入，已选图版为 figure-*.webp，文字保存在页面内。Earth渲染脚本为 earth-*.js，包含Three.js r182的MIT许可；贴图出处见 earth-attribution.json。全页收录与专题归纳分别记录，不代表每页已另写讲解或验证全部原始研究数据。整份 PDF/PPT 未上传。收藏、笔记与阅读进度仅保存在访客自己的浏览器中，支持导出和导入。

课件图版和研究材料的权利归原作者所有，来源见页面标注。本仓库未授予第三方材料新的许可。

## 发布与后续更新

GitHub Pages 使用 `main` 分支根目录，以 `index.html` 为入口。
本地继续更新知识地图后，运行 `地质知识地图/prepare_github_pages.py`，先上传生成的新增 `figure-*.webp` 和 `course-*.js` 资源，再更新 `index.html` 和本说明。文件名含内容指纹，未变资源可复用。不要上传本地维护索引、缓存、原始PDF/PPT或个人回顾记录。
