# 地质事件与研究方法 · 复习地图

以地质年代和研究方法为两条主线的中文复习工具，基于课程 PPT 导出 PDF 整理，未读取教材。

- 40 个地质事件、29 种研究方法、12 个研究案例。
- 完整地质年代表、事件磁吸聚焦、课件图版并排核对、全文检索。
- 保留原课件图版中的作者与年份，补充研究附原始来源链接。
- 图表各自保留原始坐标，不能视为共用时间轴；年龄范围及争议请查看条目说明。

此仓库发布网页成品。完整课程 PDF 未上传；已选图版及提取文字内嵌于页面。收藏与笔记仅保存在访客自己的浏览器中，支持导出和导入，不会上传至 GitHub。

课件图版和研究材料的权利归原作者所有，来源见页面标注。本仓库未授予第三方材料新的许可。

## 发布与后续更新

GitHub Pages 使用 `main` 分支根目录，以 `index.html` 为入口。
本地继续更新知识地图后，运行 `地质知识地图/prepare_github_pages.py`，再将生成的 `知识地图/github-pages/index.html` 更新至此仓库。不要上传个人收藏或笔记导出文件。
